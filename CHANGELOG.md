# Changelog

All notable changes to Taddicons. The project follows [Semantic Versioning](https://semver.org); icon names and
webfont code points stay the same from one release to the next.

## 0.3.1 (2026-11-16)

Quality pass and 2,885 new icons: 15,887 outline icons in 177 categories.

- Redrawn: 5,700 existing icons were checked one by one and redrawn where they were weak, too close to another icon or
  clipped. Names and webfont code points are unchanged.
- Letters and digits now share one height (14 units), and the PDF file icon uses a neutral format badge.
- New: 2,885 document and message icons for the latest Taddi document types.
- The set is now complete at 15,887 icons. From here on releases maintain the current base: fixes and refinements
  to existing icons, no new icons.

## 0.3.0 (2026-11-15)

The first public version line of Taddicons: 13,002 outline icons in 177 categories and eight sections.

- Documents and messages: an icon for every kind of document and message Taddi writes, from health appointments,
  renting and immigration to weddings, small business, sales outreach, school parents and official letters for 20
  countries.
- Interface, business, people, life, leisure, world and making: arrows, controls, text, files, devices, money, shapes,
  people, food, sport, travel, nature, tools and more.
- Every icon on the same 24-unit grid with the same line, as SVG, a sprite, a webfont (code points in the Private Use
  Area and Supplementary Private Use Area-A), PNG, WebP, AVIF and ICO, plus a message emoji for each icon.
